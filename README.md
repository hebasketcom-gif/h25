## Technical Features

- **Pure HTML5, CSS3, & Vanilla JavaScript** — Zero framework dependencies, zero build step required.
- **Responsive & Mobile-First** — Optimized for 4K displays, desktops, laptops, tablets, and smartphones.
- **Dark Mode Support** — Toggles between a warm cream academic theme and a deep navy dark theme, with local storage memory.
- **Accessibility & SEO** — Includes JSON-LD Person structured data, Open Graph meta tags, semantic landmarks, and full keyboard navigation.
- **Scroll & Micro-Interactions** — Smooth scrolling, scroll progress indicator, scroll reveal animations, and an interactive gallery lightbox.
- **GitHub Pages Ready** — Deploy directly without compilation.

## Deployment to GitHub Pages

To host this website on GitHub Pages:

1. Create a public repository on GitHub (e.g., `dr-praveen-pathak-portfolio`).
2. Push all project files (`index.html`, `style.css`, `script.js`, `README.md`) to the `main` branch.
3. In your GitHub repository, navigate to **Settings** > **Pages**.
4. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Your live site will be generated at `https://<your-username>.github.io/<repository-name>/`.
