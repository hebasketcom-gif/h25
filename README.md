## 🛠️ Technology Stack

This website is built with pure, lightweight web standards:

- **HTML5**: Semantic document structure with full SEO meta tags and Schema.org JSON-LD Person structured data.
- **CSS3**: Custom CSS variables, CSS Grid, Flexbox, glassmorphism, responsive typography, and custom light/dark theme system.
- **Vanilla JavaScript**: Zero-dependency scroll observer, mobile navigation drawer, theme toggle with `localStorage` persistence, scroll reading progress bar, lightbox modal, and interactive contact form handler.

*No external frameworks (React, Vue, Bootstrap, Tailwind, jQuery, PHP) or backend/database dependencies required.*

## 🚀 Deployment Instructions for GitHub Pages

To host this portfolio on **GitHub Pages**:

1. **Create a GitHub Repository**:
   - Go to [GitHub.com](https://github.com) and create a new repository named `praveen-pathak-portfolio` (or `username.github.io`).

2. **Upload Repository Files**:
   - Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `images/` directory to the root of your repository.

3. **Enable GitHub Pages**:
   - Navigate to your repository **Settings** → **Pages**.
   - Under **Build and deployment** → **Source**, select `Deploy from a branch`.
   - Under **Branch**, select `main` (or `master`) and `/ (root)`. Click **Save**.
   - Your site will be published at `https://<your-username>.github.io/` in a few moments!
