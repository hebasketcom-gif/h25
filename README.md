# Dr. Praveen Pathak — Academic Professional Portfolio

A world-class, premium single-page academic portfolio website for **Dr. Praveen Pathak**, HOD & Assistant Professor in the History Department at Starex University.

Designed with an Oxford-inspired academic aesthetic, editorial typography, responsive design, dark mode support, and interactive gallery lightboxes.

## 🎓 Academic Profile
- **Current Positions:** Head of Department (HOD) & Assistant Professor, History Department, Starex University
- **Qualifications:** PhD, MPhil, JRF (UGC), NET, SET (History), MA (History)
- **Academic Interests:** Medieval History, Gandhi Studies, Hindu Studies, Historical Analysis & Education

## 🛠️ Built With
- **HTML5:** Semantic markup & Schema.org JSON-LD structured data
- **CSS3:** Custom design tokens, CSS grid/flexbox, dark mode variables, animations
- **Vanilla JavaScript:** Zero dependencies, IntersectionObserver scroll-reveal, lightbox modal, active scrollspy, dark mode toggle

## 🚀 Deployment to GitHub Pages

This project requires **no build step, no framework compilation, and no backend server**.

### Option 1: Direct Deployment
1. Create a public repository on GitHub.
2. Push all files (`index.html`, `style.css`, `script.js`, `README.md`) directly to the `main` or `gh-pages` branch.
3. In your repository, navigate to **Settings > Pages**.
4. Select **Branch: main** and **Folder: / (root)**, then click **Save**.
5. Your site will be published at `https://<your-username>.github.io/<repository-name>/`.
